# Task ↔ GitHub Issues (1 task → N issues) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Giữ hybrid: 1 task record mỏng làm bìa hợp đồng, 1 superpowers plan làm tiến độ chi tiết, N GitHub issues con để theo dõi. Trước mỗi mốc M, coordinator chẻ record thành issues theo plan, link 3 chiều record ↔ plan ↔ issues.

**Architecture:** Giữ 1 task = 1 nhánh + 1 PR như hiện tại; issues là lát thực thi trong cùng PR (code/test/docs), PR đóng hết bằng `Closes #..`. Phân lớp hybrid: record (`.agents/tasks/<task-id>.md`) là chuẩn cho hợp đồng + trạng thái ngoài (status, base/head SHA, PR, bảng issues, link plan); plan (`docs/plans/<date>-<topic>.md`) là chuẩn cho tiến độ trong (checkbox từng bước, ledger rulings); issue là chuẩn cho trạng thái theo dõi từng lát. Khi giao việc chỉ mention 2 đường dẫn record + plan; resume đọc cả hai; lệch hợp đồng theo record, lệch tiến độ theo plan.

**Tech Stack:** Markdown skills trong `.agents/skills/`, GitHub Issue templates (`.github/ISSUE_TEMPLATE/`), `gh` CLI, Node 24 tests (`node --test`).

**Spec:** Thiết kế ngắn đã duyệt trong hội thoại 2026-11-04 (Cách 1: issue là bước giao trong cùng 1 PR; record cha ở `.agents/tasks/`, template ngắn, labels `M0..M4`/`wp-xx`/`type`, tạo idempotent, back-link số issue vào record) + quyết định hybrid 2026-11-04: record mỏng + plan superpowers giữ tiến độ, mention 2 paths khi làm.

## Global Constraints

- Định danh, comment, commit, PR title/body bằng tiếng Anh; chuỗi UI tiếng Việt theo `COPY.md`.
- Không ghi "Generated by AI", đồng tác giả AI, hay biểu tượng robot trong commit/PR.
- Mỗi PR vào `develop`, squash merge chỉ sau review PASS đúng SHA (`gh pr merge --squash --match-head-commit <sha>`).
- Task record từ `.agents/templates/task.md`, tiếng Anh; `task-id` kebab-case theo mã WP/spike.
- Không `try!`/force-unwrap trong logic Swift; Go core không `time.Now()` trong domain/service, không `net`, không biến toàn cục.
- Chạy kiểm tra sau sửa skill/tài liệu: `node --test .agents/hiraku/tests/*.test.mjs` và `node .agents/skills/hiraku-wp-status/scripts/wp-status.mjs --check`.

## Review Focus

- Chạy kickoff 2 lần tạo trùng issue (mong đợi: lần 2 không tạo mới, chỉ báo đã tồn tại).
- Record local và issue lệch số/trạng thái (mong đợi: record ghi rõ số issue nào, trạng thái nào, bên nào chuẩn).
- Template issue quá dài khiến agent bỏ trống (mong đợi: ≤ 30 dòng body, field nào cũng điền được trong 2 phút).
- Label/milestone gõ tay sai (`M0` vs `m0`, `wp-03` vs `WP-03`) (mong đợi: quy ước chữ thường, có bước kiểm).
- Issue mô tả hành vi thay vì "tests pass" (mong đợi: tiêu chí quan sát được + lệnh check cụ thể).
