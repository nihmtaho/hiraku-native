---
name: flow-pr
description: >-
  Open or update the task PR after the task branch has been pushed, with an English
  Conventional Commit title and a body written from the template, leaving no AI trace.
  Use when the senior has just pushed the branch and needs a PR, or an existing PR's
  title or body needs fixing.
compatibility: gh signed in; task branch pushed; run from the repository root.
---

Read `PROJECT.md` at the repo root first. If it is missing, stop and ask the user to
create it from the kit's `PROJECT.md.example`.

## Workflow

1. Confirm the current branch is `<type>/<task-id>-<short-summary>`, pushed, and `git rev-parse HEAD`
   matches the SHA on the remote. Working tree clean, and the `[Unreleased]` line exists
   in the changelog named in `PROJECT.md` §Docs map. If not, stop and tell the senior to
   push or add the changelog line first.
2. Check whether a PR already exists: `gh pr list --head <branch> --state all`.
3. No PR yet, create one:
   - base must be the branch named in `PROJECT.md` §Git & PR; any other base → stop;
   - title `<type>(<scope>): <subject>`, in English;
   - body written to `pr-<task-id>.md` in the scratch directory named in
     `PROJECT.md` §Docs map, from the PR template path in `PROJECT.md` §Git & PR.
     Record the exact commands run with their exit code; a check that was not run is
     written `Not run`;
   - `gh pr create --base <base> --title "<title>" --body-file <path>`.
4. A PR already exists: `gh pr edit <pr> --title ... --body-file ...`. A new push
   changes the head SHA, which voids any old review verdict; tell the coordinator.
5. Record the PR number, URL, and head SHA in the task record.
6. If the PR touches a policy or checker file listed in `PROJECT.md` §Git & PR, put a
   warning in the body: "Touches policy/checker, so a human operator should review
   before merge."

## Limits

- No merge, no closing the PR, no base other than the one in `PROJECT.md` §Git & PR,
  no `gh pr review`, no `gh api`.
- No "Generated by AI", AI co-author, robot icon, or any AI trace in the title, body,
  or commits.
- Never mark a check that was not run as passed.

## Output

PR number, URL, base, head SHA, and whether the PR touches policy/checker files.
